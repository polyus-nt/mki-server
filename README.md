# TJC Commutator — монитор SimpleBus

Приложение получает телеметрию от стенда по последовательному интерфейсу
SimpleBus и отображает её в окне с графиками. Показываются температура внутри
и снаружи стенда, заданная температура, обороты четырёх кулеров и стадия
двери.

## Возможности

- Выбор доступного COM-порта прямо в приложении.
- Приём и проверка кадров SimpleBus.
- Графики скользящего среднего `MA(7)` для внутренней и внешней температуры.
- Графики RPM: для кулеров 1–3 в диапазоне 0–3000 RPM, для кулера 4 — 0–5000 RPM.
- Отображение заданной температуры пунктирной линией.
- Цветовая индикация стадии двери на графике внутренней температуры:
  жёлтый — стадия 3–5, красный — выше 5.
- Хранение последних 1000 измерений в памяти.

## Требования

- Python 3.10 или новее;
- доступ к последовательному порту устройства;
- Windows, Linux или macOS. На Windows порт обычно называется `COM3`,
  `COM8` и т. п.

## Установка

Из корня проекта создайте и активируйте виртуальное окружение:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Установите зависимости:

```powershell
python -m pip install -r requirements.txt
```

В Linux/macOS активация окружения выполняется так:

```bash
source .venv/bin/activate
```

## Запуск монитора

```powershell
python simplebus_serial.py
```

В окне выберите COM-порт и нажмите «Подключиться». Список портов можно
обновить кнопкой «Обновить порты».

Порт и скорость можно передать при запуске:

```powershell
python simplebus_serial.py --port COM8 --baud 9600
```

Скорость по умолчанию — `9600` бод. После завершения работы закройте окно:
соединение с портом будет закрыто автоматически.

## Формат данных

Каждый пакет SimpleBus имеет пять байт:

```text
CR | AA | D | LF
```

где `CR` — `0x0D`, `LF` — `0x0A`, `AA` — двухсимвольный ASCII-адрес в
шестнадцатеричном виде, а `D` — один байт данных. Монитор принимает пакеты с
адресом `99` (`0x63`).

Телеметрия передаётся между маркерами `0x0C` и содержит строго 16 байт:

| Байты | Значение |
| --- | --- |
| 0 | Датчик Холла |
| 1 | Геркон |
| 2–3 | Температура внутри: целая и дробная части |
| 4–5 | Температура снаружи: целая и дробная части |
| 6–7 | RPM кулера 1 |
| 8–9 | RPM кулера 2 |
| 10–11 | RPM кулера 3 |
| 12–13 | RPM кулера 4 |
| 14 | Заданная температура |
| 15 | Стадия двери |

Целые температурные значения интерпретируются как знаковые однобайтные числа.
Дробная часть нормализуется в диапазон от 0 до 99 сотых. Значение RPM
декодируется из двух байт и масштабируется к диапазону 0–5000.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| `simplebus_serial.py` | Главное GUI-приложение: чтение COM-порта, разбор телеметрии и графики. |
| `simplebus_protocol.py` | Общие функции протокола: кодирование/декодирование пакетов, поиск портов, сбор данных. |
| `send-simplebus.py` | Простой пример периодической отправки одного пакета в SimpleBus. Порт в файле задан как `COM8`. |
| `reader-simplebus.py` | Простой консольный пример чтения пакетов. Порт в файле задан как `COM8`. |

## Примечания по подключению

- Закройте другие программы, использующие тот же COM-порт: одновременно
  открыть порт обычно нельзя.
- Если устройство не отображается в списке, проверьте кабель, драйвер и
  правильность скорости обмена.
- В `send-simplebus.py` и `reader-simplebus.py` при необходимости измените
  значение переменной `port` перед запуском.
