# Теплица-химреактор

Отдельный проект химреактора. Конфигурация фаблаб-теплицы в корне репозитория
не меняется и не дополняется этим оборудованием.

**Статус:** состав оборудования и распиновка согласованы. В этой папке пока
нет реализации сервиса и прошивок химреактора; существующий фаблаб-сервис
не следует запускать для управления этим стендом.

## Оборудование

| Плата | Назначение |
| --- | --- |
| Arduino sensors | MQ-2 ×2, DHT11 ×2, BMP280 ×2 |
| Arduino actuator UNO | Два PWM-вентилятора с тахометрами и реле питания |
| lmp8 | Два магнитных замка на общем выходе и отдельный релейный вентилятор |
| Кнопочница МС-ТЮК | Концевики дверей |
| Центральный хаб и Arduino-шлюзы | Доступ к аппаратным узлам через SimpleBus и Austere |

Два Arduino-вентилятора и релейный вентилятор — разные устройства.
Релейный вентилятор имеет десять рабочих уровней и отдельное выключенное
состояние 0. Пылесос фаблаб-теплицы в этот состав не входит.

## План интерфейса актуаторов

| Метод | Аргументы / результат |
| --- | --- |
| `get_pwm(idx)` | idx 0..1; применённый PWM 0..255 |
| `get_rpm(idx)` | idx 0..1; измеренные обороты в минуту |
| `set_pwm(idx, pwm)` | idx 0..1, PWM 0..255 |
| `get_door_lock()` | Состояние общего управляющего выхода блокировки |
| `set_door_lock(lock_state)` | true блокирует оба замка, false разблокирует оба |
| `get_relay_level()` | Применённый уровень релейного вентилятора 0..10 |
| `set_relay_level(level)` | Уровень 0..10; 0 выключает все реле |

Это план методов, не список уже доступных HTTP-эндпоинтов. Замки не имеют
индекса, поскольку физически управляются одним выходом. Состояние выхода
не доказывает физического срабатывания замка или вращения вентилятора.

Полная согласованная распиновка: [PINOUT.md](PINOUT.md).
Фаблаб-инструкции в `../docs/API.md` относятся к другому стенду.
