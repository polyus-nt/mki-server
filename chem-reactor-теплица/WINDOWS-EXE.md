# Windows: сборка и запуск без установленного Python

## Для того, кто собирает

Нужны Windows и установленный Python 3.10+ с `venv`/`pip`, интернет для первой
установки зависимостей. Разрядность exe соответствует разрядности Python.
Ветка репозитория: `feat/chemical-reactor-integration`.

Из корня `tjc-commutator`:

```powershell
cd "chem-reactor-теплица"
py -3 scripts/build_windows.py
```

Скрипт создаёт отдельное окружение `.venv-build`, устанавливает зависимости
из `requirements-build.txt` и запускает PyInstaller. HTML/CSS/JS включаются
в onefile exe; отдельный браузер в комплект не входит.
Он не прошивает платы, не открывает COM и не отправляет аппаратных команд.
Повторная сборка заменяет exe, но сохраняет уже существующий `dist/.../config.json`.
Не собирайте поверх запущенного exe. Для сборки с уже установленными зависимостями:

```powershell
py -3 scripts/build_windows.py --skip-install
```

Результат:

```text
dist/chemical-reactor/
  ChemicalReactor.exe
  config.json
  README.md
```

Передавайте всю эту папку или её ZIP. На компьютере получателя Python и
библиотеки не нужны. **Сборка Windows exe выполняется на Windows**, а не Linux.
Перед передачей проверьте полученный exe на целевой Windows с реальным хабом.

## Для пользователя

1. Подключите хаб МС-ТЮК к USB. Драйвер USB-платы должен быть установлен.
2. Посмотрите его COM-порт в диспетчере устройств Windows.
3. Откройте `config.json` Блокнотом и замените `COM15` на свой порт:

```json
{
  "serial_port": "COM15",
  "host": "127.0.0.1",
  "http_port": 8001
}
```

4. Запустите `ChemicalReactor.exe`. Окно с журналом оставьте открытым.
5. Откройте **http://127.0.0.1:8001/panel** в браузере.
   Полное API: **http://127.0.0.1:8001/docs**.

Для запуска не нужны Arduino IDE, Python или отдельная HTTP-консоль.
Панель содержит чтения, включающие команды и подсказки. Начните с чтения.
Если используете только теплицу без Mega реактора, пользуйтесь разделом
«Теплица»: общий selftest также проверяет отсутствующий реактор и покажет ошибки.

### Если не запускается

При ошибке запуска exe оставляет сообщение в консоли и ждёт Enter перед
закрытием окна. При штатной остановке Ctrl+C, `--help` и успешном `--list-ports`
паузы нет. При перенаправленном вводе (запуск из автоматического скрипта)
ожидание отключено; код ошибки сохраняется.

Запустите из PowerShell, чтобы увидеть ошибку даже после завершения программы:

```powershell
.\ChemicalReactor.exe --list-ports
.\ChemicalReactor.exe --serial-port COM13
```

Порт хаба может быть занят Arduino Serial Monitor, другой консолью или вторым
экземпляром сервиса — закройте их. Если порт 8001 занят, завершите старый сервис
или задайте другой `http_port`, затем откройте панель на новом порту.
Если Windows блокирует скачанный exe, проверьте источник и политику организации;
не отключайте защиту системы ради запуска.

Конфиг ищется рядом с exe, независимо от текущей папки терминала. Другой файл:

```powershell
.\ChemicalReactor.exe --config "C:\My Greenhouse\config.json"
```

Приоритет настроек: аргументы запуска → `MSTJUK_SERIAL_PORT` (только COM) →
конфиг → встроенные значения. Явно указанный, но отсутствующий/неверный конфиг
вызывает ошибку. Допустимы также `queue_capacity`, `queue_timeout`,
`exchange_timeout`, `debug`; тайм-ауты в секундах. Существующий запуск
`python -m hub_service` тоже поддерживает конфиг в папке сервиса.
`--help` показывает все параметры, `--no-debug` отключает debug из конфига.

### Остановка и безопасность

Сначала остановите двигатели кнопкой панели, потом завершите сервис через Ctrl+C.
Закрытие сервиса **не останавливает моторы**: последняя команда продолжает действовать.
Программный stop идёт общей очередью и не заменяет аварийное аппаратное отключение.
API без токенов: оставляйте `host=127.0.0.1`, если не нужен сетевой доступ.
По умолчанию браузер автоматически не открывается, оборудование не запускается.
