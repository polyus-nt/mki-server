# Распиновка теплицы-химреактора

Номера D/A относятся к Arduino UNO. Номера выводов lmp8 — к компоненту
`LED(номер)`, без обозначений GPIO STM32. Это отдельная конфигурация:
прошивки и разводка фаблаб-теплицы не подходят для неё без адаптации.

## Arduino sensors

| Устройство / сигнал | Индекс | Пин UNO |
| --- | --- | --- |
| MQ-2, аналоговый выход | 0 | A1 |
| MQ-2, аналоговый выход | 1 | A0 |
| DHT11 | 0 | D2 |
| DHT11 | 1 | D3 |
| BMP280 SCL | Общий для 0/1 | D4 |
| BMP280 SDA | 0 | D5 |
| BMP280 SDA | 1 | D6 |

Концевики находятся на МС-ТЮК, не на этой Arduino.
Распиновка связи sensors со шлюзом требует отдельного согласования;
пять транспортных пинов actuator ниже относятся только к actuator-плате.

## Arduino actuator UNO

| Вентилятор / индекс API | PWM | Тахометр | Реле питания |
| --- | --- | --- | --- |
| 0 | D10 | D8 | A0 |
| 1 | D11 | D12 | A1 |

Связь с отдельным Arduino-шлюзом по Austere:

| Сигнал | Пин UNO |
| --- | --- |
| MISO | D2 |
| MOSI | D3 |
| CLK | D4 |
| CS | D5 |
| IRQ | D7 |

D0/D1 оставлены для Serial. D13 свободен, чтобы встроенный светодиод UNO
не нагружал тахосигнал. Остальные свободные выводы: D6, D9, A2..A5.

Реле активно LOW: PWM=0 → HIGH, питание выключено;
PWM>0 → LOW, питание включено, на PWM-выход передаётся заданное значение.

## Восьмилампочница lmp8

| Пин платы | Устройство | Управление |
| --- | --- | --- |
| 1 | Два магнитных замка, общий выход | LOW блокирует оба, HIGH разблокирует оба |
| 2 | Реле вентилятора r1 | LOW включает, HIGH выключает |
| 3 | Реле вентилятора r2 | LOW включает, HIGH выключает |
| 4 | Реле вентилятора r3 | LOW включает, HIGH выключает |
| 5 | Реле вентилятора r4 | LOW включает, HIGH выключает |
| 6 | Реле вентилятора r5 | LOW включает, HIGH выключает |
| 7 | Реле вентилятора r6 | LOW включает, HIGH выключает |
| 8 | Не используется | — |

Матрица из предоставленного скетча; «Вкл.» означает LOW:

| Уровень | Включённые реле |
| --- | --- |
| 0 | Нет |
| 1 | r1, r5, r6 |
| 2 | r1, r2, r5, r6 |
| 3 | r1, r2, r3, r5, r6 |
| 4 | r1, r2, r3, r4, r5, r6 |
| 5 | r1, r6 |
| 6 | r1, r5 |
| 7 | r1, r2, r6 |
| 8 | r1, r2, r3, r6 |
| 9 | r1, r2, r3, r4, r6 |
| 10 | r1 |

При переключении сначала выключаются все шесть реле, затем выдерживается
250 мс, после чего включается новая комбинация. Названия уровней не являются
процентами и сами по себе не гарантируют монотонного изменения мощности.
Необходимы проверка силовой схемы и испытания каждой комбинации на стенде.

## Кнопочница и адресация МС-ТЮК

Концевики подключаются к кнопочнице. Номера её входов и адреса SimpleBus
плат химреактора нужно зафиксировать перед реализацией прошивок;
адреса фаблаб-стенда здесь пока не назначены автоматически.
