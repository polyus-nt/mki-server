# Domain context

## Glossary

### МС-ТЮК

Аппаратная система, предоставляющая доступ к подключённым датчикам и исполнительным устройствам через центральный хаб и шлюзы.

### Центральная плата МС-ТЮК

Аппаратный хаб, связывающий компьютер со шлюзами датчиков и исполнительных устройств.

### Arduino-шлюз

Промежуточный аппаратный узел, связывающий центральную плату с одной Arduino-платой.

### Плата датчиков

Arduino-плата, собирающая показания подключённых физических датчиков.

### Плата актуаторов

Arduino-плата, выполняющая команды воздействия на исполнительные устройства и предоставляющая связанную с ними телеметрию.

### User API

Набор операций обычного доступа к измерениям и управления вентиляторами, разрешённых управляющему ПО и агенту.

### Admin API

Полный набор операций аппаратной системы, включающий обычный доступ, управление замком и административное тестирование неисправностей.

### Админка

Интерфейс администратора для обычного и привилегированного управления аппаратной системой.

### Режим тестирования неисправностей

Административно включаемый сценарий намеренного физического изменения воздействия на один выбранный вентилятор для проверки реакции управляющей системы. Одновременно активен не более одного такого сценария. Не обозначает состояние температурного регулятора или подмену показаний оборотов.

### Текущий режим системы

Нормальная работа всей системы или единственный активный сценарий тестовой неисправности выбранного вентилятора. Остальные вентиляторы продолжают обычную работу.

### Периодическое искажение PWM

Тестовая неисправность выбранного вентилятора, при которой управляющее воздействие периодически меняется случайным образом независимо от новых команд и доступности компьютера.

### Искажение команды PWM

Тестовая неисправность выбранного вентилятора, при которой поступившее управляющее значение заменяется случайным. Без новой команды этот сценарий сам по себе не изменяет воздействие.

### Запрошенный PWM

Управляющее значение, переданное в команде установки PWM. При административном искажении может отличаться от применённого значения и не является обещанием последующего восстановления.

### Применённый PWM

Управляющее значение, установленное на выходе платы для вентилятора. Отличается от фактических оборотов вентилятора и не подтверждает его вращение.

### Концевик двери

Физический вход контроля одной двери. В целевой системе две разные двери, у каждой собственный концевик.

### Закрытая дверь

Дверь, закрытие которой подтверждено её концевиком. Это состояние отличается от блокировки магнитным замком.

### Магнитный замок

Исполнительное устройство блокировки двери. У каждой из двух дверей собственный замок. Запрошенная блокировка отличается от подтверждения физического закрытия двери.
