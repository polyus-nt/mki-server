# Конфигурации теплиц

Зафиксировано 2026-10-10: система предусматривает два объекта —
**фаблаб-теплица** и **теплица-химреактор**. Их аппаратные конфигурации различаются.
Сейчас реализуется фаблаб-теплица. Химреактор пока не реализуем: ниже записана
только согласованная распиновка, без изменения прошивок, API или серверного опроса.

## Фаблаб-теплица — текущий проект

Текущая Arduino Sensor: BMP280 ×3, SGP40 ×2, DHT11 ×3,
GP2Y1010AU0F ×2. Концевики находятся на МС-ТЮК.
Рабочая распиновка остаётся в
[BoardConfig.h](../../arduino-sensor/BoardConfig.h); описание —
[README Arduino Sensor](../../arduino-sensor/README.md).
Новая конфигурация химреактора не заменяет эту карту.

## Теплица-химреактор — запланировано, не реализовано

| Устройство / сигнал | Количество | Пины Arduino |
| --- | ---: | --- |
| MQ-2, аналоговые выходы | 2 | A1 / A0 |
| DHT11, линии данных | 2 | D2 / D3 |
| BMP280 | 2 | общий SCL D4; отдельные SDA D5 / D6 |
| Концевики | пока не уточнено | на МС-ТЮК, не на Arduino |

MQ-2 записаны как два датчика с отдельными аналоговыми выходами; это не пара
аналогового и цифрового выходов одного датчика. Порядок перечисления пинов
сохранён из требования, но индексы каналов API пока не назначены.

При реализации отдельно определим:

- транспортную распиновку Arduino ↔ МС-ТЮК Arduino-шлюз;
- индексы каналов, формат показаний и методы API для MQ-2;
- количество концевиков и их привязку к узлам МС-ТЮК;
- выбор конфигурации и адресацию двух теплиц в основной системе.

До этого текущий BoardConfig, состав каналов Hardware API v2 и зарегистрированные
MCP tools остаются без изменений. Просто загрузить текущую прошивку фаблаб-теплицы
с этой распиновкой химреактора нельзя: состав датчиков и назначение GPIO другие.
